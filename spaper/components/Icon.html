Icon

Sketchy icons from @sketchyicons/svelte. Pass an IconNode from spaper/icons.

Available icons are listed on sketchyicons.com/icons.

- colors

<script>
import { Icon } from 'spaper';
import { Heart, Star } from 'spaper/icons';
</script>

<Icon name={Heart} type="danger" size={28} />
<Icon name={Star} type="warning" size={28} />
<Icon name={Heart} type="danger" size={28} fill="danger" />

API

NameDescriptionTypeValuesDefault
nameIcon geometry. IconNode from spaper/iconsIconNode__
